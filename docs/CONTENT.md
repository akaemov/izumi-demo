# Наполнение и выпуск

Единый источник данных — `src/lib/content.ts`. Для каждой сущности хранится status: confirmed (проверено), pending (ожидается), demo (только предпросмотр). Режим задаётся NEXT_PUBLIC_CONTENT_MODE=preview|public перед сборкой. По умолчанию public; локальный .env.local включает preview. Публичная сборка не показывает референсы. Добавлены 12 условных планировок (по три студии, 1-, 2- и 3-комнатные) со статусом demo; в публичном режиме они исключены фильтром. Наличие и цены не выдуманы. Схемы — иллюстрации, не лоты ЖК.

Логотип извлечён из векторного слоя страницы 9 с сохранением пропорций. Исходный PDF и его загрузочные ссылки не публикуются. Шрифты Tenor Sans и Golos Text — Google Fonts, OFL, лицензии рядом с файлами.

## Интеграции

POST /api/enquiries всегда возвращает 503 до настройки интеграции. В интерфейсе нет формы сбора данных: нельзя публиковать фиктивный успех. Серверный адаптер lib/leads.ts оставлен неактивным. При подключении реализовать проверку входных данных, ограничение запросов, idempotency key, durable queue/receipt и защиту от дублей, затем активировать форму с явным согласием. Секреты только на сервере. Контекст квартиры должен передаваться в серверный запрос как проверяемый ID.

Карта не загружается без проверенных координат. Видео монтируется только по действию пользователя. Отчёты не создают фиктивную историю. После наполнения привести вывод project/purchase/developer/contacts к подтверждённым данным; текущие тексты сознательно фиксируют отсутствие материалов.

## Перед коммерческим выпуском

Получить данные из реестра, проверить права, подключить CRM и юридические документы. Задать CONTENT_MODE=public, удалить локальный preview override или явно переопределить переменную. Пройти npm run typecheck, npm run lint, npm test, npm run build и браузерные сценарии. Настроить реальный домен, canonical, social preview и robots (сейчас noindex), security headers и production monitoring. Исходный код опубликован в akaemov/izumi-demo, статическая сборка выгружена в ветку gh-pages. Включение Pages и доступность внешней страницы из этой среды не подтверждены.

Демонстрационный каталог: `apartments` в `src/lib/content.ts`, статус `demo`, условные площади, `available: false`, `price: null`. SVG-схемы находятся в `public/media/plans/`; повторная генерация из корня проекта: `python scripts/generate-demo-plans.py`. Это технические иллюстрации, не проектная документация. Категории каталога переключаются без потери позиции при закрытии просмотра. Для новых реальных лотов используйте статус `confirmed` и подтверждённые параметры.

Новые секции: `src/components/MarketingSections.tsx`. Плитка ценностей бренда — `brandBenefits`, список документов — `projectDocuments` в `src/lib/content.ts`. Документы пока со статусом pending: даты и файлы не выдуманы, раскрытие поясняет отсутствие официального материала. После получения настоящих файлов нужно подключить ссылки скачивания в компоненте списка.

Презентация: `public/documents/izumi-presentation.pdf` — созданная четырёхстраничная концепция, не исходный брендбук и не проектная документация. Регенерация из корня: `node scripts/generate-presentation.mjs` (Playwright и Chromium). Шапка и CTA скачивают PDF напрямую без сбора данных. Паттерн `public/media/scales.webp` извлечён из раздела «Паттерн» брендбука; на фоне философии его непрозрачность 9%.

Семейная ипотека: по решению пользователя блок демонстрационный. Поля и отправка отключены, данные не собираются; ставки, платежи и участие проекта в программе не заявлены. Для реального запуска нужны подтверждённые условия, оператор ПДн, юридические документы и серверная доставка обращений.

Коллаж «Вдохновение в движении»: `src/components/ParallaxCollage.tsx`, данные `collageLayers` в `src/lib/content.ts`. Три фотографии — референсы из фотостиля и видны только в preview; три абстрактных материала — подтверждённая графика бренда. Мазки кисти извлечены из страницы 28 PDF с сохранением прозрачности, полукружия — оригинальные векторные контуры из страницы 30, чешуя — материал страницы 29. SVG полукружий очищен от посторонних элементов страницы и содержит только два исходных контура и фон.

Параллакс использует CSS view timeline на одном блоке. Нет вложенного скролла, перехвата колеса или новых JS-библиотек. На мобильном амплитуда 30% от desktop; reduced-motion полностью отключает движение. При отсутствии поддержки view timeline сохраняется статический коллаж. Блик с фотографий удалён по запросу пользователя.
