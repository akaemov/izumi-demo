# Проверка реализации

Проверено в текущей облачной среде (Node 24, системный Chromium):

- `npm run typecheck` — успешно.
- `npm run lint` — успешно, без предупреждений после исправлений.
- `npm test` — 2 теста: изоляция demo-контента и фильтрация подтверждённых доступных лотов.
- `npm run build` — production build preview-режима успешен.
- `NEXT_DIST_DIR=.next-public NEXT_PUBLIC_CONTENT_MODE=public npm run build` — публичная сборка успешна.
- `npx playwright test` — 4 проверки прошли: 1440px и 390px, навигация/меню, галерея и Escape, фильтры/сброс, пустые данные, недоступный приём обращений, ошибки изображений, длинный заголовок, отсутствие горизонтального скролла и ошибок JS.
- Отдельная проверка публичной сборки в Chromium: нет demo-фотографий и preview-уведомления; пустая галерея; /privacy возвращает 200; нет горизонтального скролла на 390px и 1440px.
- POST /api/enquiries возвращает 503, не ложное подтверждение отправки.
- Скриншоты desktop и mobile просмотрены; логотип и типографика проверены визуально.

Квартира с реальной планировкой, реальные видео, фотоотчёты, карта, банковские программы и CRM не проверялись на реальных данных: материалы и доступы не предоставлены. Пустые состояния проверены. Проверки не устанавливают готовность к коммерческому запуску. Внешняя публикация и восстановление среды в новой задаче не выполнялись.

## Анимации

Добавлены через Web Animations API и CSS, без дополнительных runtime-зависимостей. Первый экран раскрывается мягко, секции появляются однократно через IntersectionObserver, меню/диалог/галерея используют короткие переходы. В поддерживающих браузерах CSS scroll timeline показывает тонкий индикатор чтения. Нет JS-обработчика прокрутки, захвата скролла и обязательной задержки перед взаимодействием.

`PAGES_TEST_URL=http://127.0.0.1:3011/izumi-demo/ node tests/pages-motion.mjs` прошёл на 390px и 1440px: запуск появления секции; немедленная отмена при переключении reduced-motion; отсутствие анимаций меню/диалога/галереи при reduced-motion; читаемый контент без JavaScript; отсутствие горизонтального скролла, ошибок JS и HTTP. Для static export исключён streaming loading fallback: HTML остаётся видимым без гидратации. Typecheck, lint, тесты данных и Pages build прошли.

Piermont не удалось осмотреть: сетевой прокси вернул CONNECT 403. Эффекты реализованы самостоятельно под айдентику «Изуми», без заявления о точном воспроизведении референса.

## Демонстрационный каталог и скругления

Добавлено 12 маркированных схем (4 категории по 3 варианта), три колонки на desktop, одна на узком мобильном экране. `tests/pages-catalog.mjs` прошёл на 390/820/1440px: все категории, 12 разных SVG, просмотр планировки, возврат фокуса, сохранение категории и контекста схемы при обращении; радиус 10px; отсутствие ошибок HTTP/JS и горизонтального скролла. `tests/pages-motion.mjs` повторно прошёл на 390/1440px. Проверка данных: 3 теста, включая исключение demo-квартир из публичного режима. Typecheck, lint, Pages build успешны; desktop и mobile скриншоты просмотрены.

Анимация применяется отдельно к заголовкам и изображениям; MutationObserver подключает новые карточки после переключения категорий без обработчика скролла. Reduced-motion продолжает отключать эффекты. Цена, этаж и наличие демонстрационных схем не выдаются за реальные данные.
